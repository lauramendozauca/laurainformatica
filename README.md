# laura-informatica
## Proyecto para la demostración de las paginas web
El proyecto esta dirigido para estudiantes de la universidad de Cadiz 
## Objetivos

- Demostrar capacidad técnica: Mostrar el dominio de tecnologías frontend y backend (según corresponda), aplicando buenas prácticas de código limpio, modular y reutilizable.
- Garantizar la adaptabilidad (Responsive Design): Asegurar que el sitio web ofrezca una experiencia de usuario óptima y fluida en diferentes dispositivos, desde teléfonos móviles hasta pantallas de escritorio.
